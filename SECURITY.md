# Security Policy

## Supported versions

No release is tagged yet. Once releases exist, only the latest tagged release
is supported.

## Reporting a vulnerability

Report privately with GitHub private vulnerability reporting: open the
repository's Security tab and select *Report a vulnerability*. Do not open
public issues for suspected security problems.

This extension runs inside Pi and reads only local skill files; it performs no
network calls and writes no files outside Pi's own widget/event system.
